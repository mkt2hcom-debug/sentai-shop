Tài khoản dành cho chủ cửa hàng.

Chưa cấu hình tài khoản quản trị. Xem README để thiết lập ADMIN_PASSWORD trên máy chủ.

Quên mật khẩu?

Trên máy đang chạy web, mở RESET-ADMIN.cmd rồi dùng liên kết hiện ra để đặt mật khẩu mới.

Hoặc chạy npm run admin:reset trong thư mục web. Liên kết dùng một lần, có hiệu lực 20 phút.
